# brentoncodes.dev

Source for my personal portfolio and developer site — built with Next.js and a custom earthy design system, focused on performance and accessibility.

🔗 [Live Site](https://brentoncodes.dev)

## Features

- Custom design system (not a template) — [describe: color palette, typography choices]
- Scroll-triggered animations
- Built to WCAG 2.2 accessibility standards throughout

## Tech Stack

Next.js, TypeScript, Tailwind CSS

## Running Locally

```bash
git clone https://github.com/brenthippler-art/brenton-codes.git
cd brenton-codes
npm install
npm run dev
```
